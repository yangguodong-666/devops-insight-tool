# DevOps Insight Tool

A lightweight DevOps inspection and reporting tool built with Python.

## Features
- Batch SSH server health checks (uptime, disk, memory)
- Jenkins CI/CD build status collection via API
- Automated daily report generation (Markdown)
- Designed for multilingual teams (EN / CN / ES compatible)
